Two real bugs in the prompt that will trip the build agent

The Task 2 code calls:

But the actual export in escalationService.ts is:

Different name, different signature (takes a context object, not positional args). Bug 2 — businessSettings.businessAddress does not exist (Task 1 silently regresses)

I checked business_settings (schema.ts lines 1910–~2000) and neither field exists. The closest is homeBaseAddress on the customers table — wrong table — and address on appointments — also wrong.
