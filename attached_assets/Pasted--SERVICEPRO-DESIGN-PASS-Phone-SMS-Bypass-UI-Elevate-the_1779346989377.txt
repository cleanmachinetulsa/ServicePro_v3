## THE REDESIGN

Replace the current emergency bypass section with this structure. Keep all existing functionality and save logic — only change the visual presentation.

### Design principles
- Status-first: the owner sees their current routing state instantly at a glance
- Two-state cards: inactive = subtle, active = prominent colored indicator
- No amber/warning colors for the inactive state — that creates false urgency
- Active state uses a clear, distinct color (red for bypass modes, green for normal)
- Mode cards use radio-card pattern (full card is clickable, not just a radio button)
- Mobile-first: works at 375px without horizontal scroll
