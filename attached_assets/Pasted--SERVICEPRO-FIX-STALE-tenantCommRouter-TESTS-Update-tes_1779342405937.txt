## WHAT IS BROKEN AND WHY

`server/tests/tenantCommRouter.test.ts` has failing tests that assert `resolveTenantFromInbound()` returns `tenantId: 'root'` and `resolvedBy: 'fallback'` for unresolved inputs.

The **code is correct**. The **tests are stale**. The function was deliberately updated with this comment in the source: `// R1-STRICT: NO fallback to 'root' - return null tenant for caller to handle`. The old root fallback was a single-tenant hack. The correct multi-tenant behavior is to return `tenantId: null` and `resolvedBy: 'unresolved'` when no phone config matches.

**Do not change `server/services/tenantCommRouter.ts`.** Only update the tests.
