## THE FIX — THREE TARGETED CHANGES

### Change 1 — Create `useTenantMeta` hook (new file)

Create `client/src/hooks/useTenantMeta.ts`.

This hook:
- Calls the existing API endpoint that returns `businessName` (found in verification step 3)
- Uses `useQuery` with no placeholder/initial data — only real server data
- On successful response: sets `document.title` to the business name
- On successful response: if `logoUrl` is a valid non-empty string, updates the favicon
- Returns nothing the caller needs — side-effect only hook

```typescript
// Pseudocode — adapt to actual endpoint shape and query pattern used in this codebase

import { useEffect } from 'react';
import { useQuery } from '@tanstack/react-query';

export function useTenantMeta() {
  const { data } = useQuery<{ businessName: string; logoUrl?: string | null }>({
    queryKey: ['/api/YOUR-ACTUAL-ENDPOINT-HERE'],
    staleTime: 1000 * 60 * 10, // 10 min — business name rarely changes
  });

  useEffect(() => {
    if (!data?.businessName) return;
    document.title = data.businessName;
  }, [data?.businessName]);

  useEffect(() => {
    if (!data?.logoUrl) return;
    const link = document.querySelector<HTMLLinkElement>("link[rel~='icon']");
    if (link) {
      link.href = data.logoUrl;
    }
  }, [data?.logoUrl]);
}
```

**Critical rules:**
- No `placeholderData`, no `initialData`
- `document.title` only updates when `data?.businessName` is a real non-empty string
- Favicon only updates when `data?.logoUrl` is a real non-empty string
- If either is null/undefined/empty: leave the existing value in place (don't blank it)
- Use the exact same `useQuery` pattern as the rest of the codebase — check an existing
  hook before writing to match the convention (`apiRequest`, `fetch`, `ky`, etc.)

### Change 2 — Call the hook in the app root

Find the single component that wraps every route — likely `App.tsx` or a root layout
component. Add one line:

```typescript
useTenantMeta(); // sets document.title + favicon from tenant branding
```

This must be in a component that:
- Renders on every page
- Is inside the `QueryClientProvider`
- Is inside whatever auth context exists (so the user/tenant is resolved)

If `App.tsx` is outside the `QueryClientProvider`, find the inner wrapper that is inside it.

### Change 3 — Update `client/index.html` default title

Change the hardcoded `<title>` in `client/index.html` to a neutral platform default
that shows briefly before the JS resolves:

```html
<title>Loading...</title>
```

This prevents "ServicePro" from flashing before the real tenant name loads.
Keep the existing `<link rel="icon">` pointing to the ServicePro favicon as the default —
it will be overwritten at runtime when the hook runs if a tenant logo is configured.
