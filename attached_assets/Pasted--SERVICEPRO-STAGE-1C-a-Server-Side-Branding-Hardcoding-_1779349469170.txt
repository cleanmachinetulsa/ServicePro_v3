Customer-facing server output — SMS messages, invoices, email copy — contains hardcoded
Clean Machine strings. Every future tenant gets Clean Machine's name, review URL, and
payment handles in their communications. This task replaces all of it with
tenant-config-driven values.

**Clean Machine is live.** Every change must produce identical output for Clean Machine
after the fix. The values come from their existing `businessSettings` / branding row —
nothing changes for them, it just stops being hardcoded.

## THE FIXES

### Fix 1 — invoiceService.ts

For every hardcoded "Clean Machine Auto Detail", Google review URL, or brand string:

1. Confirm the function has `tenantId` in scope. If not, add it as a parameter.
2. Call `await getTenantBranding(tenantId)` once at the top of the function (or pass
   the already-fetched branding object in if the caller has it).
3. Replace hardcoded strings with branding fields:
   - Business name → `branding.businessName`
   - Google review URL → `branding.googleReviewUrl` (from businessSettings after migration)
   - If review URL is null/empty: omit the review section entirely, do not render a broken link

Check every call site of the modified functions — if callers don't pass `tenantId` yet,
add it at the call site too. Follow the chain up until tenantId is in scope.

### Fix 2 — dashboardApi.ts (ETA SMS)

Find the ETA SMS template that hardcodes the business name:

1. Confirm `tenantId` is available in `navigateAndSendETA` (or its caller).
2. Fetch branding: `const branding = await getTenantBranding(tenantId)`
3. Replace hardcoded name with `branding.businessName`

### Fix 3 — dashboardApi.ts (Payment handles)

If Venmo/CashApp handles are hardcoded:
- Check `businessSettings` for an existing payment handle column.
- If a column exists: use it, with empty-string fallback (omit section if blank).
- If no column exists: **do not add one in this task**. Remove the hardcoded handles
  and omit the payment section. Flag in completion report under `DEFERRED ITEMS` with
  the exact column name you'd recommend adding (e.g. `venmo_handle`, `cashapp_handle`).

### Fix 4 — Any other files from the grep

Apply the same pattern to every additional file the grep surfaces:
- Get `tenantId` in scope
- Fetch branding once
- Replace hardcoded strings
- Omit sections where the replacement value is null/empty rather than showing broken output
